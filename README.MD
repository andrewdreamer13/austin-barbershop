## 📌 Project Overview
A commercial landing page built for a vintage-style barbershop in Austin, Texas. The primary focus of this project is high-performance asset management, responsive fluid design, and clean typography that captures the authentic retro atmosphere while maintaining modern web standards.

---

## 🛠️ Tech Stack & Methodology
* **HTML5:** Semantic markup, accessibility (a11y) basics.
* **SCSS / BEM:** Modular architecture, CSS custom properties, fluid layout (`clamp()`).
* **JavaScript (ES6+):** Vanilla JS for lightweight interactive components.
* **Vite:** High-performance build tool & module bundler.

---

## 💎 Key Highlights
* **Performance First:** Optimized SVG icons, modern text typography, and fast loading speeds.
* **Pixel-Perfect & Responsive:** Fluid layout scaling smoothly from smartphone screens to large desktop monitors.
* **Clean Code Architecture:** Scalable SCSS structure following BEM guidelines for easy maintenance.
